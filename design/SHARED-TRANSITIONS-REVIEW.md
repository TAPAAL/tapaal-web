## Code review notes (what was checked)

- **Source model** (`authored-shared.ts`): closed `SharedTransition {id,name,urgent}`; member occurrences closed to geometry plus `angle` (a place member with `angle` fails the existing `validateNet` rotation rule through the projection). Pool IDs/names are unique across both kinds and against every local name in every component, including inactive ones. One occurrence per pool per component. Member urgency, ages and invariants are rejected in component timing. Untimed urgent pools are refused. The shared/shared incidence check is endpoint-based (`isMember(from) && isMember(to)`), so it covers normal, output, inhibitor and both transport arcs in every component (review spec: output, transport-in and transport-out in an inactive component; implementation spec: normal and inhibitor). Local transitions using shared places still validate.
- **Commands**: create/edit/delete pool, make/use/detach/remove/copy/patch all go through one expected-source identity check and whole-source validation, so there is one snapshot and one history. Adoption of a differing urgency needs `acceptPoolValues`. Cross-kind `usePool`/`makeShared` IDs are refused. Detach validates the fresh name and copies urgency. `removeOccurrence` removes incident arcs and both halves of transport pairs. Queries protect unused pool symbols; the urgency semantic edit stays allowed. `removeQueries` is undoable.
- **Execution** (`shared-network-simulation.ts`): one physical transition per pool, created only from active members. Arcs and local places are compiled only for active components, so inactive members neither constrain nor change tokens. `transitionId` rejects refs into inactive components. All-inactive pools create no event and no urgency blocker. Physical IDs are tagged JSON tuples, so the shared `pool` tag for both kinds is safe because pool IDs are cross-kind unique. Bindings for shared events use the qualified physical arc key, while local transitions keep their old local-ID interface. `validateTimedModel` is run on the compiled model.
- **Codec** (`shared-files.ts`): declarations must be direct, unprefixed root children in the PNML namespace. Allowed root attributes are `name, urgent, player, weight, firingMode, distribution, value`. Root/member agreement is checked after defaults, and the scalar inspector then refuses agreed but unsupported values. Verified refusals (none were silently dropped): `firingMode="Oldest"`, `player="1"`, `weight="2"` and `weight="K"`, `distribution="uniform"`, `distribution="constant" value="2"`, member `priority="3"`, `infiniteServer="true"`, `urgent="TRUE"`, root-only `firingMode`, member-only urgency, nested and prefixed declarations, duplicate declarations, place/transition name collision, and unknown root attributes. Explicit native defaults (`player="0" weight="1.0" firingMode="Random" distribution="constant" value="1.0"`) are accepted. Names `__proto__` and `constructor` load safely (Map-based). Transition-named members without a root declaration stay disjoint locals.
- **JSON V3**: old V3 with `transitions: []` and place-only protections (no `protectedSharedTransitions`) reopens identically. `protectedSharedTransitions` is emitted only when transition pools exist at capture time.
